## 四、判据：什么算「同一个体型」

分工原则是「**一眼能认出来的身体**独立成类，剩下的按体深与头部构型分栏」：

| 体型 | 判据（剪影特征） |
|---|---|
| `slender` | 体深 ≤ 约 1/4，长身、尖吻、鳍靠后 |
| `minnow` | 小型溪流鱼，短圆身、钝头、软尾 |
| `deep` | 体深 ≥ 约 1/2，侧扁高身、小尾 |
| `carp` | 粗壮高背、大鳞、口部有须（鲤鲫鲢鳙草青鲮鲃） |
| `reef` | 礁岩型：大头、厚唇、圆尾（石斑 / 鲷 / 鲻 / 鮸） |
| `perch` | 纺锤 + **两段背鳍** + 尖齿（鲈 / 鳜 / 石首鱼类） |
| `bottom` | 贴底：眼睛挪到头顶、宽胸鳍（鲬 / 鲉 / 鰕虎 / 鳚 / 鳕 / 合鳃） |
| `catfish` | 扁头 + 长须（鲶 / 鮠） |
| `fangfish` | 深海巨口：细身、巨口、针状牙（灯笼鱼 / 尖牙鱼 / 帆蜥鱼 / 叉齿鱼…） |
| `flatfish` | 侧躺，两只眼都在朝上一侧，周缘一圈连续鳍（鲽 / 鲆 / 鳎） |
| `sturgeon` | 骨板列 + 长吻 + 吻下须 + 上叶长的歪尾（鲟） |
| `mackerel` | 流线 + 小鳍列 + 新月尾（马鲛 / 金枪 / 鲯鳅 / 竹荚 / 鲹） |
| `billfish` | 长而硬的吻（「剑」）+ 高背帆（旗鱼 / 剑鱼） |
| `anglerfish` | 巨口 + 头顶挑着一根诱饵（鮟鱇 / 树须鱼 / 鬼灯笼） |
| `puffer` | 圆钝无尾柄、鳍极小（河鲀 / 箱鲀 / 单棘魨 / 鳞鲀 / 翻车鲀） |
| `seahorse` | 直立 + 卷尾 + 管状吻（海马） |
| `pomfret` | 短圆身 + 几乎不分叉的小尾（鲳） |
| `salmon` | 流线 + 背鳍后一枚**脂鳍**（鳟 / 鲑） |
| `manta` | 翼状大盘 + 口前一对「角」（蝠鲼） |

## 五、这一动会不会让已出的图作废？（逐条对拍过）

**结论：前面五个钓场 178/182 条逐字未变。** 判据是「把新体型映射回旧值，两条提示词逐字比对」（`_tmp/prompt_retag_check.py`）：

| 范围 | 结果 | 说明 |
|---|---|---|
| D / C / B / A / S（182 条） | **178 条逐字未变** | 改的只是分类标签，图上没有任何变化 —— 这 178 条的 1068 张卡不用重出 |
| 同上 · 比目鱼（4 条：A16 / A17 / A29 / S15） | 提示词变了 | **故意的**：给 `flatfish` 加了专属措辞 —— 原句「浅腹 + 深背」对一条躺着的鱼是错的 |
| SS / SSS（180 条） | 53 条变了 | 这 53 条的体型锚点句从「a fish-like creature of the deep」换成了对应体型（鲟 / 比目 / 鮟鱇 / 旗剑…）—— **这就是「细分画风」落地的地方** |
| SS / SSS 其余 127 条 | 未变 | 体型没动（`fish` 只剩 5 条兜底，全在 D/B/SS/SSS） |

## 六、还顺带改了什么

- `manta`（蝠鲼形）从 `ray` 拆出来：`ray` 21 → 18 条，3 条**改名**（SS20 碎星魟 → 碎星蝠鲼、SS33 星云鳐 → 星云蝠鲼、SSS62 空之翼鳐 → 空之翼蝠鲼），它们的逐条描述（`DEEP_LINES`）本来就写着「翼」。
- `C16 溪石斑`：`perch` → `minnow`。名字里的「石斑」是俗称，它其实是溪流里的鲤科小型鱼（`reef` 那一栏的提示词会天天对它误报，所以顺手改对了）。
- 程序化剪影（游戏内图鉴解锁前那张影子 / `?dev`）新增 19 个：轮廓真换了原型的 5 个（圆钝盘 / 扁盘 / 直立 / 翼状 / 巨口）另写 hull，其余走参数化变体。
- 图鉴与评审台的「体型」筛选项自动变成 37 个（chip 上带条数、按条数降序）。

## 七、想推翻某一条怎么改

改 `tools/gen-fish.py` 的 `FIELD_FISH` 表**第三列**（`shape`），然后按顺序跑：

```
python tools/gen-fish.py && node tools/solve-drop.js \
  && node tools/fix-rarity-price.js && node tools/fix-rarity-price.js \
  && node tools/gen-collect-time.js && node tools/verify.js
```

⚠️ `fix-rarity-price.js` 要跑到「0 条」为止；重生成 `fish.js` 会冲掉档内权重 `w`，所以 `solve-drop.js` 必须跟着跑。
