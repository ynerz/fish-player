## 风格约定（我的理解，请指正）

| 项 | 做法 |
|---|---|
| **语气** | 冷幽默 + 博物学观察。**笑点建立在真实习性上**，不是硬编段子 |
| **人称** | 第二人称/旁观叙述混用，避开"这条鱼很漂亮"这类空话 |
| **长度** | 普通 **1 句** / 稀有 **1~2 句** / 史诗 **2~3 句** / 传说 **3~4 句** |
| **五档差异** | 见下：每档文案换个角度写，**不是换形容词** |
| **禁忌** | 不写"可爱""霸气"这类评价词；不剧透数值；不用感叹号堆情绪 |

**五档的叙事角度**（这是"不同颜色介绍也略微不同"的落地方式）：

| 档 | 角度 |
|---|---|
| **原色** | 讲**习性/生态**——它平时是怎么活的 |
| **亮色** | 讲**视觉奇观**——彩虹色带来的荒诞后果 |
| **白化** | 讲**生存代价**——没了保护色，日子不好过 |
| **黄金** | 讲**人的反应**——渔民/收藏家/经济学 |
| **闪光** | 讲**它的光本身**——像什么、别人怎么反应 |

# 普通档（1 句）

## A01 沙丁鱼
- **原色**：海里最著名的群众演员。一辈子都在演"被吃掉的那个"，靠数量硬是演成了整个食物链的基石。
- **亮色**：传说吃了彩虹沙丁鱼能许一个愿。至今无人验证——它们通常在许愿之前就被更大的鱼吃掉了。
- **白化**：白化沙丁鱼在鱼群里格外显眼。这在沙丁鱼的社会里不叫与众不同，叫优先被吃。
- **黄金**：通体流金的沙丁鱼。渔民捞到它都得愣一下：这玩意儿该拿去卖钱，还是该供起来？
- **闪光**：游起来像一小片会动的星图。别的鱼看两眼就晕——不是被美到，是被闪到。

## A03 黑鲷
- **原色**：背鳍上一排硬棘，脾气跟长相一样硬。钓鱼人管它叫"海里的钉子户"——咬钩之后基本不挪窝。
- **亮色**：彩虹版黑鲷，硬刺配上花花绿绿的鳍。它自己似乎不太满意这个配色，游姿比平时暴躁三成。
- **白化**：白化黑鲷只剩一身硬刺还算醒目。没有保护色，它唯一的防御手段是"看起来不好惹"。
- **黄金**：金色的黑鲷。老渔民说看见它要放生——不是因为迷信，是因为刺太扎手，不好处理。
- **闪光**：一身星点的黑鲷从水里升上来，像块镶了碎钻的磨刀石。

## A14 海鳗
- **原色**：长得像一条会生气的绳子。白天躲在礁缝里，晚上出来巡逻，是礁石区公认的"夜班保安"。
- **亮色**：彩虹海鳗在水里扭动时，像有人把一条彩虹掉进了礁石缝，还在里面拧麻花。
- **白化**：白化海鳗远看像一条漂在水里的旧绷带。它自己大概不这么认为。
- **黄金**：有人管它叫"黄金锁链"。名字很好听，但它其实是专门用来缠住不听话的渔网的。
- **闪光**：一条镶满星屑的绳子，在水里无声地拧来拧去。夜潜的人看到它，第一反应是"那是什么"，第二反应是"那是活的"。

## A16 鲽鱼
- **原色**：出生时两只眼睛是分居的，长大后其中一只会"搬家"到另一边——这是海洋里最著名的家庭纠纷。
- **亮色**：彩虹鲽鱼躺在沙底上，像一块有人不小心掉在海里的彩色瓷砖。
- **白化**：白化鲽鱼趴在沙底上几乎完美隐身。问题在于它自己也找不到自己了。
- **黄金**：金色的鲽鱼贴在海底，远看像谁掉的一枚巨大金币。捡不捡，是个哲学问题。
- **闪光**：星点从沙底浮起来，像海底有人正在展开一张会发光的餐巾。

## D01 麦穗鱼
- **原色**：老家在河沟里，长得像麦穗，胆子比麦穗还小。钓它最大的难点是它比你更快意识到"这是个陷阱"。
- **亮色**：彩虹麦穗鱼。体型没变，还是那么小，但至少现在它闪得让人找得到。
- **白化**：白化麦穗鱼在水里像一粒泡发的米。它自己似乎因此获得了某种神秘的安全感。
- **黄金**：麦穗大小的一粒金。放在手里会让人产生"我是不是发现了什么"的错觉。
- **闪光**：一条会眨眼的小银线。水流一动，它就成了整条溪里最忙的那个光点。

# 稀有档（1~2 句）

## A21 石斑鱼（示例位）
- **原色**：礁石区的地头蛇。不动的时候是石头，动的时候是灾难——张嘴的负压能把小鱼直接吸进去。
- **亮色**：彩虹石斑。有经验的潜水员会绕开它——不是怕它咬人，是怕它那身颜色把自己看晕。
- **白化**：白化石斑趴在礁石上像块被漂白的珊瑚。优点是好看，缺点是很久没抓到东西了。
- **黄金**：金色的石斑鱼。捕到它要拍照，因为放回水里你也说不清刚才看到了什么。
- **闪光**：一颗会呼吸的星团。它在礁缝里张合呼吸的样子，像海底某处正在缓慢地眨眼。

## A25 黄鳍鲷
- **原色**：鳍是黄色的，脾气是硬的。它咬钩的第一反应不是跑，是"我跟你讲道理"。
- **亮色**：彩虹鳍的黄鳍鲷。颜色很热闹，性格依旧冷硬，属于"穿得最花、话最少"的那一类。
- **白化**：白化黄鳍鲷只剩那对鳍还有点颜色。它似乎把全部的倔强都转移到了那两个地方。
- **黄金**：通体金色的黄鳍鲷。渔民遇到它通常不拍照——因为此时手上全是刺。
- **闪光**：金色的身体上浮着细碎的星点，像有人把一小片夜空塞进了一条鱼里。

## A30 银鲳
- **原色**：身体薄得像被人压过。游动时是海里最像"纸片"的鱼，也是餐桌上最受欢迎的那一张。
- **亮色**：彩虹鲳鱼，薄薄一片彩色玻璃在水里翻。它大概不知道自己在吃货眼里并不是观赏鱼。
- **白化**：白化银鲳薄如蝉翼且颜色近白，趴在水里基本等同于"透明"，捕食者常常游过去才发现刚才错过了什么。
- **黄金**：金色的薄片在水中翻动，像一枚有人不小心掉进海里的纪念章。
- **闪光**：一小片会游的星空。它实在太薄，以至于那些星点看起来像是在水面上浮动。

# 史诗档（2~3 句）

## S60 深海龙鱼（示例位）
- **原色**：深海没有光，所以它自己带。嘴里那排牙向内弯，是"进去容易出来难"的物理呈现。
  它一辈子没见过太阳，也不知道上面还有个世界。
- **亮色**：彩虹化的深海龙鱼在漆黑的深海里拖出一道彩色光带。它自己看不见自己的颜色——
  这是整片海里最昂贵的浪费。
- **白化**：色素褪尽之后，它的身体几乎透明，只剩下内脏的轮廓和那排牙。
  深海探测灯照过去的时候，很多人才第一次意识到：牙是可以单独存在于黑暗里的。
- **黄金**：通体金色的深海龙鱼。矿工们看照片的第一反应是"这得值多少钱"，
  第二反应是"它离我们至少两千米"。
- **闪光**：它身上的星点会随着下潜深度改变密度。理论上，一条闪光龙鱼的全盛状态，
  看起来就像一小片被压缩在深海里的银河。

## S62 巨齿鲨（示例位）
- **原色**：一种活在化石和恐惧里的生物。没人确认过它现在还在不在，
  但每个深海渔民都能讲出一个"我朋友的叔叔见过"的故事。
- **亮色**：彩虹巨齿鲨。传说这东西如果真存在，那它大概是海里唯一有资格挑颜色的捕食者。
- **白化**：白化的巨齿鲨如果存在，会在深海里显出一片模糊的灰白。
  有人认为那些"幽灵鲨"的目击记录就是这么来的——不是因为看到了，而是因为看不清。
- **黄金**：通体金色的传说。收藏家的说法是："就算它真的存在，见到它的人也不会回来卖钱。"
- **闪光**：一整片会移动的星海。老船员说闪光巨齿鲨出现的夜晚，海面像是倒扣了星空——
  当然，也可能是他们那晚酒喝多了。

## S65 皇带鱼（示例位）
- **原色**："地震鱼"的名声是它自己挣来的。它平时待在一千米以下，
  一旦出现在浅水，岸上的人就要开始检查房屋结构了。
- **亮色**：彩虹皇带鱼浮上水面，像一条从天上掉下来的、正在掉色的传说。
- **白化**：白化皇带鱼被冲上岸时，很多人第一反应是"这是龙吗"，第二反应是"这也太长了吧"。
- **黄金**：金色的皇带鱼在民间直接升级成"龙王亲戚"。科学协会的态度则是：先量长度，再谈身份。
- **闪光**：它游过的水面会留下一条断续的银光，像某种正在被删除的星图。

# 传说档（3~4 句）

## SS78 星陨王座·裂空皇带
- **原色**：皇带鱼家族里活得最久的一条，据说年龄以世纪计。
  它背上的冠鳍高过成年人，游动时像一面缓慢移动的旗帜。深海探测仪第一次拍到它时，
  三条船上的研究员同时安静了十秒——然后开始检查设备是不是坏了。
- **亮色**：关于它身上为什么会有彩虹，民间有七种说法，
  科学界的态度是"暂不评论"。唯一公认的是：任何试图用鱼缸装它的方案，
  都在设计阶段就被否决了。
- **白化**：褪成白色的裂空皇带在深海灯光下近乎透明。
  有人形容它像"一整条被漂白的闪电"，也有人说更像"一段安静的、自己会动的白噪音"。
- **黄金**：整条鱼像被浇了一层熔化的黄金，连那些细小的棘刺都在反光。
  它的名字里那个"王座"不是白叫的——这片海里，没有别的生物配得上这个配色。
- **闪光**：传说它全身的星屑是"沉入海底的星星留下的碎片"，每当它上浮一层，
  身上的光就重新排列一次。见过它的人后来都改了职业——一半去写诗，一半去做了深海摄影。

## SS81 幽墟之主·无光鲸
- **原色**：它黑得不像生物，更像一片被剪下来的深海本身。
  声呐图上它的回波只有别的鲸的三分之一，工程师一度以为是设备故障。
  它也不着急，游得很慢，像是根本不担心被发现——毕竟它所在的地方，本来就没有光。
- **亮色**：彩虹色的无光鲸是海洋生物学界最大的一个笑话。
  因为理论上不可能——它连反射光都做不到，哪来的颜色？
  但每个声称见过的人，描述都出奇地一致。
- **白化**：当它全身褪成白色浮上浅海，整片海面会安静下来。
  不是说它在捕猎，而是它实在太大了——大到其他生物需要十几秒才能反应过来"那是个什么东西"。
- **黄金**：有人算过，如果把这条鲸按黄金计价，它的身价能买下整个渔港。
  但没人真的这么算过第二遍，因为算完之后，所有人都开始担心渔港的安危。
- **闪光**：它身上的光点分布和其他任何生物都不同——没有规律，也不随水流动。
  深海观测站记录过它一次完整的上浮，全部数据后来被归档进了"无法解释"那一栏。

## SS85 时之环·巡界龙鱼
- **原色**：它的鳞片是环状的，一圈套着一圈。潜水员描述说，盯着它看久了会不舒服——
  不是因为害怕，而是因为那些环"看起来在转"，但照片里又是静止的。
- **亮色**：彩虹色的巡界龙鱼是最常被误认成海市蜃楼的生物之一。
  渔民的说法很朴素："你看到一道会动的彩虹从水下游过去，你就知道，今天别下网了。"
- **白化**：白色的巡界龙鱼在深海里像一轮安静的月。
  有记录显示，某些深海鱼群会绕着它游——科学解释是"趋光性"，
  当地渔民的版本是"它们也不知道自己在干什么"。
- **黄金**：它那身金色比一般的黄金沉，据说接近它会感到一种"被什么古老的东西打量"的压力。
  这种说法从未被证实，但记录里所有与它合影成功的人，都笑得很勉强。
- **闪光**：环状鳞片配上星屑，游动时像一圈正在旋转的银河。
  有人为它写了长达四百页的研究报告，结论只有一句：
  "我们目前只能确认——它确实很亮。"

## SSS92 终焉之瞳·万钧鮟鱇
- **原色**：深海最著名的"陷阱"。额头前那根发光的小杆子不是装饰，是诱饵——
  而它本人就趴在一米外的黑暗里，保持着一个耐心到令人不适的微笑。
  海洋学家给它起了个外号，叫"海底的坏主意"。
- **亮色**：彩虹版的鮟鱇鱼，诱饵也跟着变成了彩色的。
  说实话，这让它看起来更像骗局了——自然界里没有哪种猎物是这么花里胡哨地等在门口的。
- **白化**：白化的它诱饵依旧发光。有人说这更可怕：在一片纯粹的黑暗里，
  一小团白色的光静静悬着，而你知道那后面有一张能吞下自己的嘴。
- **黄金**：通体黄金的鮟鱇。收藏界的说法是，它的诱饵"比整条鱼都值钱"。
  它本人对此没有意见——毕竟诱饵坏了它还会再长。
- **闪光**：当它的诱饵亮到极致，整片深海会短暂地像白天。
  那一刻，所有被吸引过来的生物都会看清那张嘴，然后做出它们一生中最正确的决定——
  虽然通常已经太晚了。
