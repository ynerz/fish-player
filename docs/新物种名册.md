## 为什么走「换物种」而不是「修提示词」

这 102 条**全都有查证过的真实物种**（`fish-traits.json` 里每条都带 `species` 拉丁学名 + `form`）。也就是说图「不像」不是因为提示词写得糙，而是**硬按真实物种画**这条路本身走不通（深海异形鱼按真实解剖画出来就是一团）。⇒ 不再当真实鱼，改成**虚构生物**。

## 两条命名规则

1. **SS / SSS 保留主题词、只换物种**：`陨铁鲷 → 陨铁蟹`、`星蚀鲷 → 星蚀螺`、`陨光海蛇 → 陨光蛇尾` ——用户刚逐条审过，认得出是哪一条；而材质句（`Raw dark ore is fused over …`）大多仍成立，只需把「身体部件」换掉（body → shell / coil）。

2. **D / S 这两场是写实向的**（村口小池塘 / 幽蓝海沟），名字原来就是真实物种，换成**同水域里另据一格的生物**（螺 / 蟹 / 虾 / 沙蚕 / 水母 / 老鳖）。
