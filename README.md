# 🎣 钓鱼人生 · Fish Player

一款纯前端的单机钓鱼游戏：**抛竿 → 等咬钩 → 张力拉扯 → 收进图鉴**。
7 个钓场、112 种鱼、4 级稀有度、6 档颜色变异、6 套可切换画风，程序化绘制与合成音效，**零依赖、零构建**。

> 策划文档见 [`docs/GDD.md`](docs/GDD.md)（所有数值、掉率表、实测平衡数据都在里面）

---

## 快速开始

**最简单**：双击 `index.html` 就能玩（不依赖任何服务端）。

**推荐**（避免个别浏览器对 `file://` 的限制）：

```bash
cd "D:/fish player"
python -m http.server 8765 --bind 127.0.0.1
# 然后浏览器打开 http://127.0.0.1:8765/
```

## 操作

| 操作 | 说明 |
|---|---|
| **抛竿** | 点右下角按钮 / 点画面 / 按 `空格` |
| **提前收杆** | 等待期间点按钮，放弃这一竿 |
| **提竿** | 咬钩时浮漂下沉，1.2~1.6 秒内点按钮 |
| **收线** | 拉扯时**按住**按钮 / 鼠标左键 / `空格` |
| **放线** | 松手。张力太高会断线，一直松着会脱钩 |
| **躲逃窜** | 出现"要逃窜了"提示时立刻松手 |

## 目录结构

```
index.html              唯一入口（所有脚本按顺序加载，兼容 file://）
assets/css/style.css    全部样式
src/data/               纯数据层：数值配置 / 钓场 / 鱼种 / 道具
src/core/               逻辑层：抽卡 · 存档 · 拉扯玩法 · 钓鱼状态机 · 音效
src/render/             Canvas 渲染：鱼类绘制器 · 场景
src/ui/                 HUD 与各类弹层
src/main.js             启动与主循环
tools/                  数值仿真与调参脚本（不参与游戏运行）
docs/GDD.md             策划文档
```

## 调数值

**所有平衡参数集中在 `src/data/config.js`**，改完直接刷新页面即可。
鱼种掉率在 `src/data/fish.js`（每种鱼行末的 `w` 是同档位内的抽取权重，调小即变稀有）。
节奏表在 `tools/solve-drop.js` 的 `FIELD_HOURS`。

```bash
node tools/solve-drop.js  # 改完节奏目标后跑这个：反推整套掉率并写回数据
node tools/balance.js     # 复核：胜率 / 节奏 / 每小时收益 / 集齐图鉴耗时
node tools/tune.js        # 扫描 dashPower，自动找合适的拉扯难度
node tools/check-roster.js # 看各钓场鱼种与档位分布
```

## 美术风格

6 套画风可一键切换（`G.FishArt.setStyle('bold')`），
对比图见 [`docs/style-preview/`](docs/style-preview/)，也可直接打开 `tools/style-preview.html` 交互查看。

## 存档

保存在浏览器 `localStorage`（键 `fishplayer.save.v1`，另有 `.bak` 备份）。
设置面板可一键导出到剪贴板。清浏览器缓存会丢档。

## 平台路线

- **当前**：纯 Web 单机版
- **下一步**：微信小程序（需替换存储 / 音频 / Canvas 适配层）
- **再下一步**：Steam（Tauri / Electron 打包 + Steamworks 成就与云存档）

美术与音效均为程序化生成，没有外部素材文件，包体极小，便于多端移植。
