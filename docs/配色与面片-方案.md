## 二、根因（两条都不是「措辞不好看」，而是**取色 / 面片读法**的结构问题）

### 2.1 Q5：传说鱼拿到的色是**取模取出来的残数**

`gen-fish.py` 里每条鱼的色是 `pal[i % len(pal)]`（`PALETTES[钓场]` 一条色带按序号取），
而传说鱼是每个钓场的**最后几条** ⇒ 它们必然落在**色带的头部或尾部**：

| 钓场 | 传说那条落在色带第几位 | 实得色相 |
|---|---|---|
| D（16 条 / 14 色） | 1 | 205° |
| C（24 / 22） | 1 | 204° |
| B（34 / 32） | 0、1 | 197°、201° |
| A（46 / 44） | 43、0、1 | 216°、203°、201° |
| S（62 / 54） | 3~7 | 205°、214°、12°、165°、210° |
| SS（80 / 64） | 10~15 | 226°、252°、225°、227°、224°、224° |
| SSS（100 / 68） | 23~31 | 214°、326°、256°、256°、270°、267°、249°、240°、203° |

**色带的第 0 位就是该钓场的「基础色」，而七个钓场的基础色全是同一个偏青蓝的灰蓝**
（`#cfd9e0` / `#b7cbd8` / `#c8d2d6` / `#b9cbd6` / …）。
⇒ D / C / B 三场的传说鱼**取到了取模后的第 0~1 位 = 那个灰蓝**；
SS 场那一段（10~15 位）本身是一串深蓝；SSS 场 23~31 位又是一串蓝紫。
**「85% 挤在青蓝」不是配色品味问题，是「传说恰好落在色带同一头」的必然结果。**

### 2.2 Q29：两档的偏离方向相反，而各自的**面片措辞**正是元凶

- **黄金（5.19，偏碎）**：它用的是**默认** `GEOM`（`a dense triangular polygon mesh`），
  而黄金族 5 条颜色句里有大量「在面片层面上」的高光词 ——
  `sharp brilliant specular **reflections across the facets**`（`golden/2`）、
  `brilliant golden sheen, high luminance`（`golden/1`）。
  **「across the facets」等于命令模型在每个面片上都点一块高光** ⇒ 色块数被高光切碎。
- **闪光（1.29，偏少）**：它在 2026-10-08 已经有一句专属的 `GEOM_COARSE`
  （当年用户口径：「闪光档不用是以前很多面的格式，防止有些部分看起来像小像素块」），
  那句明确写着 `no dense mesh, no busy micro-facets`。
  ⇒ **降到 1.29 是那次改动的结果**，方向是用户要的，只是**幅度**没人量过。

## 三、三个选项（含代价）

### 3.1 Q5 · 传说配色

| 选项 | 做什么 | 代价 | 评价 |
|---|---|---|---|
| **A（推荐）** | 给**传说档**单开一张 `LEGEND_COLORS`（27 条按稀有度取色，色相**均匀铺开**：赤/橙/金/翠/靛/紫/银白各几条），不再走 `pal[i % len]` | **只影响 27 条传说**的 `body`/`accent` ⇒ 传说卡过期 **27 × 7 = 189 张** | 改点集中（取色那一行 + 一张表）；且可加一条**可机器验的判据**：传说档 30° 档不许出现「某档 0 条而另一档 >6 条」 |
| B | 重排七个色带（让第 0 位不再是各场同一个灰蓝） | **影响全部 362 条**的取色 ⇒ 2534 张卡全过期 | 代价不成比例，**不建议** |
| C | 不动，把「传说偏冷色」当既定风格 | 0 | 可接受；但 Q5 当初是用户自己提的 |

### 3.2 Q29 · 黄金 / 闪光的面片密度

| 选项 | 做什么 | 代价 | 评价 |
|---|---|---|---|
| **A（推荐）** | ① 黄金档新增一句**中间档**面片措辞（`GEOM_MEDIUM`：介于 `GEOM` 与 `GEOM_COARSE` 之间），挂上 `GEOM_BY_MORPH["golden"]`；② 闪光档把 `GEOM_COARSE` **往回收一点**（把它从 1.29 拉向 2.5 下限） | 只影响这两档 ⇒ 362 × 2 = **724 张**过期（可以并进正在攒的那一趟重出） | 两档各自只有一个旋钮，A/B 好做 |
| B | 只改**颜色句**（黄金去掉 `across the facets` / 降 `high luminance`；闪光弱化 `star-shaped sparkle`） | 同样是 724 张，但动的是**用户拍板过的句子** | 颜色是用户口径，**动它要单独确认** |
| C | 不动，把「靶子 3.6」改成**按档分别定靶**（黄金 4~5.5、闪光 1~2） | 0 | 最省；但「发碎 / 太素」这两个观感问题原样留着 |

> ⚠️ 我倾向 **3.1 A + 3.2 A**：两处都**只碰一个旋钮**、只影响各自的档位，而且都能配一条机器判据。
> ⚠️ **不建议**动 `LIGHT` / `BASE` / `BG` —— 那三块是「好看」的来源（v9 标定过），碰了会连累所有档。
