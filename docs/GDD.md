## 1. 一句话定位

一款**轻量、挂机友好、收集驱动**的钓鱼游戏。玩家从村口小池塘起步，
靠"钓满一个钓场的图鉴"逐级解锁更深、更怪、更值钱的水域，最终抵达隐藏的 **星陨之渊** 与 **时之尽头**。

平台路线：**先做纯 Web 单机版 → 再上微信小程序 / Steam**。

---

## 2. 核心循环

```
抛竿 ──▶ 等待咬钩（10s ~ 10min，由鱼的稀有度决定）
          │
          ▼
       咬钩窗口（约 1.2 ~ 1.6 秒，必须提竿）
          │
          ▼
       张力拉扯博弈（7s ~ 80s，按住收线 / 松开放线 / 躲逃窜）
          │
          ▼
       结算 ──▶ 金币 + 图鉴登记 + 可能解锁新钓场
          │
          └──▶ 回到底部，继续抛竿
```

一竿的渔获在**抛竿瞬间就已经决定**（只是不告诉玩家），所以"等待时长"和"最终钓到什么"
是同一份随机结果的两个侧面 —— 大鱼就是要等更久，这是设计上刻意的。

## 3. 钓场系统

### 3.1 七个钓场

| 序号 | 等级 | 名称 | 定位 | 参考时长 | 内部稀有度权重（普/稀/史/传） |
|---|---|---|---|---|---|
| 1 | D | 村口小池塘 | 新手钓场 | 开局长驻 | 88 / 10 / 1.8 / 0.2 |
| 2 | C | 溪流浅滩 | 溪流钓场 | 约 1 小时 | 85 / 12 / 2.5 / 0.5 |
| 3 | B | 湖心半岛 | 湖泊钓场 | 约 3 小时 | 81 / 14.5 / 3.7 / 0.8 |
| 4 | A | 深海断崖 | 近海钓场 | 约 30 小时 | 77 / 17 / 4.9 / 1.1 |
| 5 | S | 幽蓝海沟 | 深海钓场 | 约 100 小时 | 73 / 19.5 / 6.0 / 1.5 |
| 6 | SS | 星陨之渊 | **隐藏** | 约 300 小时 | 69 / 22 / 7.1 / 1.9 |
| 7 | SSS | 时之尽头 | **终极隐藏** | 约 1000 小时 | 65 / 24.5 / 8.2 / 2.3 |

> **关于「最多 5 个钓场」**：原始设定里写了「最多 5 个钓场 d c b a s」，
> 但同时又列出了 ss / sss。已按 **5 个显性（D~S）+ 2 个隐藏（SS / SSS）= 共 7 个**实现。
> 若你要的确实是"只有 5 个"，把 `fields.js` 里 SS / SSS 两条删掉即可，其余逻辑无需改动。

### 3.2 解锁规则

- **显性钓场（C / B / A / S）**：本钓场图鉴收集达到 **80%** 即可解锁下一个。
  - 例如 D 有 8 种鱼，需要钓到 7 种（`ceil(8 × 0.8) = 7`）。
- **隐藏钓场（SS / SSS）**：前面**所有**钓场图鉴 **100% 收满**。
  - SS 需要 D / C / B / A / S 全部 100%；SSS 需要含 SS 在内全部 100%。

> **重要实现说明**：按你的口径「**只需要收藏即可**」，当前版本**「设计时长」不作为硬性门槛**，
> 只作为节奏参考展示在钓场面板里。
> 想让时长也变成硬门槛，把 `src/data/fields.js` 顶部的
> `G.UNLOCK_HOURS_AS_GATE = false` 改成 `true` 即可，无需改动其它代码。

### 3.3 已完成/未完成的钓场回退

已解锁的钓场可以**随时回到任意一个**重钓（面板里点一下即可），用于补图鉴。

## 4. 鱼的状态：品种 × 颜色 × 重量

每条鱼由三个维度共同定义，共 **98 种品种**：

| 维度 | 内容 | 说明 |
|---|---|---|
| **品种** | 98 种（D8 / C10 / B12 / A14 / S16 / SS18 / SSS20） | 决定外形、稀有度、基础价、体重区间 |
| **颜色** | 6 档变异 | 原色 76% / 亮色 15% / 暗色 6% / 白化 2.2% / 闪光 0.7% / 黄金 0.1%，售价系数 1.0 ~ 4.0 |
| **重量** | 每种鱼独立区间 | 偏小值分布（指数 2.1），另有 3% 概率出「巨物」（体重 ×1.55），售价最高可到 2.6 倍上限 |

**售价公式**

```
售价 = 鱼种基础价 × clamp(实际重量 / 该鱼种中位重量, 0.40, 2.60)
                   × 颜色系数
                   × (首次钓到该鱼种 ? 3.0 : 1.0)      ← 图鉴奖励
```

> 图鉴一旦登记**永久保留**，卖出鱼不影响收集进度（对应你的口径）。

### 4.1 稀有度分档（4 级）

| 稀有度 | 颜色标识 | 上鱼等待时长 | 颜色标 | 说明 |
|---|---|---|---|---|
| 普通 | 灰 `#8b98a5` | **8 ~ 22 秒** | | 每个钓场 4~6 种 |
| 稀有 | 蓝 `#2b8fe0` | **38 ~ 100 秒** | | 每个钓场 3~6 种 |
| 史诗 | 紫 `#8b5cf6` | **150 ~ 320 秒** | | 每个钓场 1~6 种 |
| 传说 | 金 `#e8901a` | **380 ~ 600 秒** | | 每个钓场 1~3 种 |

> 关于「平均 20 秒一条」：原始设定同时写了「平均 20s 中一条」与「稀有鱼 40s~10 分钟」，
> 两者数学上无法同时成立（稀有鱼占比一高，均值一定被拉高）。
> 本作的取舍是：**普通鱼单竿约 20~30 秒（含拉扯），D 钓场整体平均约 35 秒**，
> 随钓场等级递增到 SSS 的约 72 秒。这样既保住了"普通鱼很快"的手感，又给稀有鱼留足了仪式感。
> 想更贴近 20 秒，只需下调 `config.js` 里各稀有度的 `timeMin / timeMax`。

## 5. 核心玩法：张力拉扯

钓到鱼之后进入**拉扯博弈**，这是本作唯一需要操作的地方。

### 规则

- 按住（**鼠标左键 / 空格**）→ **收线**：进度上涨，张力上涨
- 松开 → **放线**：进度缓慢回落，张力下降
- 鱼会不定时**逃窜**，逃窜期间张力急剧上升；逃窜前 0.55 秒有**预警**（UI 提示"要逃窜了"）
- **张力触顶**并持续 0.45 秒 → **断线**，鱼跑掉
- **张力贴地**（< 6）并持续 1.6 秒 → **松线脱钩**，鱼跑掉
- **进度到 100%** → 成功上岸
- 进度超过 20% 后鱼会**逐渐力竭**（最多减 22% 挣扎强度），保证对局一定能收敛，也符合真实钓鱼手感

### 实测胜率（模拟玩家，各 6 万次对局）

| 稀有度 | 熟练玩家胜率 | 熟练耗时 | 普通玩家胜率 | 主要失败原因 |
|---|---|---|---|---|
| 普通 | 100.0% | 7.3 s | 100.0% | — |
| 稀有 | 99.6% | 21.9 s | 93.0% | 断线 7.0% |
| 史诗 | 91.2% | 30.2 s | 91.8% | 断线 7.0% |
| 传说 | 80.5% | 39.3 s | 73.5% | 断线 26.3% |

> 熟练玩家 = 反应 0.15s、看预警就松手；普通玩家 = 反应 0.32s、节奏更迟钝。
> 想调难度：改 `config.js` 各稀有度 `fight.dashPower`（逃窜强度，最敏感的参数）。

## 7. 挂机系统

- 自动抛竿 → 自动提竿 → 由 AI 自动驾驶完成拉扯
- **代价：稀有（稀有/史诗/传说）权重 ×0.95**（对应设定里的「稀有鱼概率下降 5%」）
- 挂机时不会弹出每一条鱼的结算卡，只在**史诗 / 传说 / 新图鉴**时弹提示，避免刷屏
- 页面关闭期间开着挂机的话，回来会**离线补算**（上限 8 小时），并弹一份收获报告

> **付费定位说明**：设定里挂机是**月卡**功能。当前单机版**免费开放**，
> 开关放在 `config.js` 的 `monetization.idleIsSubscribed`，上线前改为 `true` 即可收口。

## 9. 存档结构

存储在浏览器 `localStorage`，键名 `fishplayer.save.v1`（另有 `...v1.bak` 备份副本）。

```
{
  v, coin, playTime, field, unlocked{},
  book: { fishId: { n, maxKg, colors{key:count}, first } },
  baits{}, baitSel, rods[], rodSel, lines[], lineSel, decors[],
  stats: { casts, catches, escapes, snaps, idleCatches, maxKg, maxKgFish, totalValue },
  settings: { sound, volume, ambient, idle },
  lastSeen, createdAt
}
```

支持版本迁移（`migrate()` 会为缺失字段补默认值）、损坏时自动回退到备份。
设置面板提供**导出存档到剪贴板**。

## 10. 技术架构

**纯 HTML5 + Canvas 2D + 原生 JS，零依赖、零构建**。
刻意**不使用 ES Module**，这样 `index.html` 可以被**双击直接打开**（`file://` 协议下 ES Module 会被 CORS 拦截）。

```
index.html                  唯一入口
assets/css/style.css        全部样式
src/data/config.js          所有平衡数值（唯一调参入口）
src/data/fields.js          7 个钓场 + 场景主题色
src/data/fish.js            98 种鱼（紧凑元组格式）
src/data/items.js           鱼饵 / 鱼竿 / 鱼线 / 装饰
src/core/util.js            随机数、颜色、格式化
src/core/audio.js           Web Audio 程序化音效（无音频素材文件）
src/core/loot.js            掉率 / 重量 / 颜色 / 售价（游戏与仿真共用）
src/core/state.js           存档、图鉴、解锁、商店
src/core/fight.js           张力拉扯玩法
src/core/fishing.js         钓鱼主循环状态机
src/render/fishart.js       参数化鱼类绘制器（9 种体型模板）
src/render/scene.js         Canvas 场景渲染（天空/水面/码头/钓手/粒子）
src/ui/hud.js               顶栏、底栏、按钮、提示
src/ui/panels.js            钓场/图鉴/商店/统计/设置/结算卡
src/main.js                 启动与主循环
tools/balance.js            数值仿真：胜率、节奏、收益、集齐耗时
tools/tune.js               参数扫描：自动找合适的逃窜强度
```

美术与音效**全部程序化生成**，没有任何图片 / 音频素材文件 —— 便于后续上小程序（包体小）。
