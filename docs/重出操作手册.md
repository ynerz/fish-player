## 2. 开跑（断点续跑，随时可以停）

```bash
# ② 重出「过期的全部」（--skip-existing 与 --stale 现在共用同一份判据，所以它只补真正过期的）
$PY tools/gen-art.py --skip-existing

# 想限制时长（到点干净收工，剩下的下次续跑）：
$PY tools/gen-art.py --skip-existing --budget-min 180

# 只想先看某一批（清单里有批次号）：
$PY tools/gen-art.py --batch 37 --skip-existing

# 只出一档（例如只想重出闪光）—— 注意它会把该档的每一版都重出：
$PY tools/gen-art.py --skip-existing --only-morph shiny
```

- 出到一半被打断**没关系**：`--skip-existing` 会从断的地方继续（判据是「文件在 + 台账一致」）。
- 每出一张：新图先落到 `assets/cards/_tmp/`，成功后才替换正式文件，**旧图自动归档到
  `assets/cards/_superseded/<时间戳>/`**（所以旧图不会丢，想对比随时能翻回去）。
- 出图轮**收尾会自己刷新** `docs/生图清单.md`（按磁盘现状重算勾），不用手动跑 `--plan`。

## 3. 闪光两个版本：**出完之后挑一个**

**新口径（2026-10-10）**：**所有稀有度**的闪光都出 **2 版**（以前只有传说档）。
两版是同一个池子里的两个候选，颜色句不同：

| 版 | 文件 | 颜色句 |
|---|---|---|
| 第 1 版（**正式**） | `<id>-shiny.png` | `shiny/1` 星点 |
| 第 2 版（**候选**） | `<id>-shiny-2.png` | `shiny/7` 本色 + 金属亮片 |

游戏读的是**第 1 版**（主文件名）。所以「挑最好看的」＝ 把选中的那版**扶正**：

```bash
# ③ 先看看哪些鱼有两版可挑（列出两版各自的颜色句）
$PY tools/pick-card.py --list
$PY tools/pick-card.py --list --morph shiny     # 只看闪光

# ④ 把某条鱼的第 2 版扶正（例：A44 断崖之王·巨型石斑）
$PY tools/pick-card.py A44 shiny 2
$PY tools/pick-card.py A44 shiny 2 --dry        # 先干跑看看会发生什么

# ⑤ 看大图对比：双击 tools\评审台.cmd，缩略图里「闪光」与「闪光·第2版」是相邻两格
$PY tools/review-cards.py                       # 重跑一次评审台，缩略图才会换成新的
```

- 工具做的是**对换**：文件对换 + `manifest.json` 里两个槽位的记录一起对换
  （只换文件不换台账 = 台账开始描述另一张图，而且**不报错**）。
- ⚠️ **不要手工改名**、**不要删掉落选那版** —— 清单的「完成」判据是「母版 + 每一档每一版都在」，
  少一版会让这条鱼**永远打不上勾**，下一轮还会去把它补回来。
- **再跑一次同一条命令就换回来**（想反悔不用别的操作）。
