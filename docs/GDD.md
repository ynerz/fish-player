# 钓鱼人生 · 游戏策划文档（GDD）

> 版本 **v0.2.0** ｜ 单机版 ｜ 最后更新：2026-10-06
> **本文档所有数值均与代码同源**：`src/data/config.js`、`fields.js`、`fish.js`、`items.js`

---

## 1. 一句话定位

一款**轻量、挂机友好、收集驱动**的钓鱼游戏。玩家从村口小池塘起步，
靠"收集本钓场图鉴"逐级解锁更深、更怪、更值钱的水域，最终抵达隐藏的 **星陨之渊** 与 **时之尽头**。

平台路线：**纯 Web 单机版 → 微信小程序 / Steam**。

---

## 2. 核心循环

```
抛竿 ──▶ 等待咬钩（8 秒 ~ 10 分钟，由鱼的稀有度决定）
          │
          ▼
       咬钩窗口（1.2 ~ 1.6 秒，必须提竿）
          │
          ▼
       张力拉扯博弈（7 秒 ~ 40 秒，按住收线 / 松开放线 / 躲逃窜）
          │
          ▼
       结算 ──▶ 金币 + 图鉴登记 + 可能解锁新钓场
          │
          └──▶ 回到底部，继续抛竿
```

一竿的渔获在**抛竿瞬间就已经决定**（只是不告诉玩家），所以"等待时长"和"最终钓到什么"
是同一份随机结果的两个侧面 —— 大鱼就是要等更久，这是刻意的。

## 3. 钓场系统

### 3.1 七个钓场（5 显性 + 2 隐藏）

| 等级 | 名称 | 定位 | 鱼种 | 解锁条件 | **预计累计时长** | 本场收满 |
|---|---|---|---|---|---|---|
| D | 村口小池塘 | 新手钓场 | 6 | 开局即开放 | — | ~1 h |
| C | 溪流浅滩 | 溪流钓场 | 8 | D 图鉴 80% | **~1 h** | ~2 h |
| B | 湖心半岛 | 湖泊钓场 | 12 | C 图鉴 80% | **~3 h** | ~7 h |
| A | 深海断崖 | 近海钓场 | 16 | B 图鉴 80% | **~10 h** | ~20 h |
| S | 幽蓝海沟 | 深海钓场 | 18 | A 图鉴 80% | **~30 h** | ~70 h |
| SS | 星陨之渊 | **隐藏** | 24 | D~S 全部 100% | **~100 h** | ~200 h |
| SSS | 时之尽头 | **终极隐藏** | 28 | D~SS 全部 100% | **~300 h** | ~404 h |

**全部 7 个钓场 100% 收满 ≈ 703 小时。**

> **时长怎么来的**：先用 `tools/solve-drop.js` 反解每场的掉率，
> 使「集齐该场图鉴的期望耗时」命中上面这张表；再用 `tools/balance.js`
> 按游戏真实掉率跑蒙特卡洛复核。两者对得上才会写进数据。
> **时长不是解锁门槛**，只是展示给玩家的预期。

### 3.2 解锁规则（代码实现）

- **显性钓场（C / B / A / S）**：本钓场图鉴收集达到 **80%** 即解锁下一个。
  - D 有 6 种鱼 → 需 5 种；C 有 8 种 → 需 7 种；以此类推（`ceil(n × 0.8)`）。
- **隐藏钓场（SS / SSS）**：前面**所有**钓场图鉴 **100% 收满**。
  - SS 需要 D~S 全 100%（共 60 种）；SSS 需要 D~SS 全 100%（共 84 种）。
- 已解锁的钓场**可以随时回去**补图鉴。

## 4. 鱼的状态：品种 × 颜色 × 重量

每条鱼由三个维度共同定义，共 **112 种品种**。

| 维度 | 内容 | 说明 |
|---|---|---|
| **品种** | 112 种（6 / 8 / 12 / 16 / 18 / 24 / 28） | 决定外形、稀有度、基础价、体重区间 |
| **颜色** | 6 档变异 | 原色 76% / 亮色 15% / 暗色 6% / 白化 2.2% / 闪光 0.7% / 黄金 0.1%，售价系数 1.0 ~ 4.0 |
| **重量** | 每种鱼独立区间 | 偏小值分布（指数 2.1），另有 3% 概率出「巨物」（体重 ×1.55） |

**售价公式**

```
售价 = 鱼种基础价 × clamp(实际重量 / 该鱼种中位重量, 0.40, 2.60)
                   × 颜色系数
                   × (首次钓到该鱼种 ? 3.0 : 1.0)      ← 图鉴奖励
```

> 图鉴一旦登记**永久保留**，卖出鱼不影响收集进度。

### 4.1 稀有度分档

| 稀有度 | 颜色标识 | 上鱼等待 | 说明 |
|---|---|---|---|
| 普通 | 灰 `#8b98a5` | **8 ~ 22 秒** | 每场 4~9 种，构成绝大多数渔获 |
| 稀有 | 蓝 `#2b8fe0` | **38 ~ 100 秒** | 每场 1~8 种 |
| 史诗 | 紫 `#8b5cf6` | **150 ~ 320 秒** | 每场 1~7 种 |
| 传说 | 金 `#e8901a` | **380 ~ 600 秒** | 每场 0~5 种，一场的"毕业鱼" |

| B | 87.629% | 7.889% | 4.319% | 0.163% | 39.6 s | 湖心巨鲤 | 615 竿 |
| A | 72.022% | 18.942% | 8.518% | 0.518% | 43.8 s | 黑潮之王·蓝鳍金枪 | 1,158 竿 |

> **为什么 D 和 C 没有传说鱼？**
> 因为「D 钓场 1 小时收满」这个节奏，和「有一条需要几百竿才能钓到的鱼」在数学上无法共存。
> 所以传说档从 B 钓场才开始引入 —— 这也让"第一次钓到传说"更有仪式感。
> C 的传说（溪灵·金线鲃）其实是全服最"好学"的传说，37 竿就能见到，作为教学很合适。

### 4.3 同一档位内的"追赶鱼"

每个稀有度档位内部用的是**几何递减权重**（`w` 值），越靠后的鱼越难见：

| 档位 | 档内差距（第一条 : 最后一条） |
|---|---|
| 普通 | 1 : 1.6 |
| 稀有 | 1 : 2.5 |
| 史诗 | 1 : 3.5 |
| 传说 | 1 : 5.0 |

这条梯度让"每个档位里都有一条难搞的"，是图鉴收集的主要动力来源。
要单独调某一条鱼，直接改 `fish.js` 里它行末的 `w` 值（调小即变稀有）。

## 5. 核心玩法：张力拉扯

### 规则

- 按住（**鼠标左键 / 空格**）→ **收线**：进度上涨，张力上涨
- 松开 → **放线**：进度缓慢回落，张力下降
- 鱼不定时**逃窜**，逃窜期间张力急剧上升；逃窜前 0.55 秒有**预警**
- **张力触顶**并持续 0.45 秒 → **断线**，鱼跑掉
- **张力贴地**（< 6）并持续 1.6 秒 → **松线脱钩**，鱼跑掉
- **进度到 100%** → 成功上岸
- 进度超过 20% 后鱼会**逐渐力竭**（最多减 22% 挣扎强度），保证对局收敛，也更像真实钓鱼

### 实测胜率（各 6 万次对局）

| 稀有度 | 熟练玩家 | 熟练耗时 | 普通玩家 | 耗时 | 主要失败原因 |
|---|---|---|---|---|---|
| 普通 | 100.0% | 7.3 s | 100.0% | 7.3 s | — |
| 稀有 | 99.2% | 22.7 s | 94.0% | 19.7 s | 断线 6.0% |
| 史诗 | 91.9% | 30.1 s | 91.1% | 30.6 s | 断线 7.8% |
| 传说 | 77.8% | 37.9 s | 73.6% | 35.4 s | 断线 26.3% |

> 熟练 = 反应 0.15s、看预警就松手；普通 = 反应 0.32s、节奏更迟钝。
> **调难度**：改 `config.js` 各稀有度的 `fight.dashPower`（逃窜强度，最敏感的参数），
> 改完跑 `node tools/tune.js` 可以扫描出目标胜率对应的值。

## 7. 挂机系统

- 自动抛竿 → 自动提竿 → 由 AI 自动驾驶完成拉扯（AI 水平写在 `config.idle.auto`）
- **代价：稀有（稀有/史诗/传说）权重 ×0.95**（对应设定里的「稀有鱼概率下降 5%」）
- 挂机时不弹每一条鱼的结算卡，只在**史诗 / 传说 / 新图鉴**时弹提示，避免刷屏
- 页面关闭期间开着挂机的话，回来会**离线补算**（上限 8 小时），并弹一份收获报告

> **付费定位**：设定里挂机是**月卡**功能。当前单机版**免费开放**，
> 开关在 `config.js` 的 `monetization.idleIsSubscribed`，上线前改为 `true` 即可收口。

## 9. 美术风格（6 版可选）

**所有鱼都是 Canvas 程序化绘制，没有任何图片素材。**
同一套几何形状，通过 `G.FishArt.STYLES` 这组参数就能渲染出完全不同的画风，
切换只需一行：`G.FishArt.setStyle('bold')`。

对比图见 [`docs/style-preview/`](style-preview/)（6 风格 × 10 种体型的完整对照表）。

| 风格 | key | 特征 | 适合什么 |
|---|---|---|---|
| **扁平卡通** | `flat` | 柔渐变 + 极细描边 | **当前默认**。清爽易读，多端适配最省事 |
| **粗描边卡通** | `bold` | 厚轮廓 + 双色平涂 | 辨识度最高，缩成图鉴小图标也分得清种类 |
| **水彩柔光** | `water` | 半透明叠色 + 晕染 + 纸纹 | 最治愈，走情绪向 |
| **写实渐变** | `real` | 多段渐变 + 高光 + 鳞片纹理 | 拟真感最强，但开发与素材成本最高 |
| **霓虹剪影** | `neon` | 压暗鱼身 + 发光轮廓 | 三个夜钓场氛围最好，白天场景偏暗 |
| **像素风** | `pixel` | 低分辨率 + 硬边放大 | 复古可爱，素材复用度高 |

**结论倾向**：推荐 **扁平卡通**（当前）或 **粗描边卡通**。
理由：本作的图鉴有 112 种鱼，缩到小图标还要能分辨是核心体验，粗描边的辨识度最优；
而程序化绘制 + 扁平填色在微信小程序的低端机上性能最好。

## 10. 技术架构

**纯 HTML5 + Canvas 2D + 原生 JS，零依赖、零构建**。
刻意**不使用 ES Module**，这样 `index.html` 可以被**双击直接打开**（`file://` 下 ES Module 会被 CORS 拦截）。

```
index.html                  唯一入口
assets/css/style.css        全部样式
src/data/config.js          所有平衡数值（唯一调参入口）
src/data/fields.js          7 个钓场 + 场景主题 + 预估时长
src/data/fish.js            112 种鱼（紧凑元组格式，含档内权重 w）
src/data/items.js           鱼饵 / 鱼竿 / 鱼线 / 装饰
src/core/util.js            随机数、颜色、格式化
src/core/audio.js           Web Audio 程序化音效（无音频素材文件）
src/core/loot.js            掉率 / 重量 / 颜色 / 售价（游戏与仿真共用）
src/core/state.js           存档、图鉴、解锁、商店
src/core/fight.js           张力拉扯玩法
src/core/fishing.js         钓鱼主循环状态机
src/render/fishart.js       参数化鱼类绘制器（9 种体型 × 6 套风格）
src/render/scene.js         Canvas 场景渲染
src/ui/hud.js               顶栏、底栏、按钮、提示
src/ui/panels.js            钓场/图鉴/商店/统计/设置/结算卡
src/main.js                 启动与主循环

tools/balance.js            数值仿真：胜率 / 节奏 / 收益 / 图鉴耗时
tools/tune.js               参数扫描：自动找合适的逃窜强度
tools/solve-drop.js         掉率求解器：反推掉率以命中节奏表
tools/check-roster.js       鱼种档位分布检查
tools/style-preview.html    美术风格对比页（出图用）
```

### 数值工具链（改数值的标准流程）

```bash
# 1. 改了节奏目标 → 反推掉率并写回 fields.js / fish.js
node tools/solve-drop.js

# 2. 复核：胜率、每小时收益、图鉴收集耗时
node tools/balance.js

# 3. 改拉扯难度 → 扫描逃窜强度
node tools/tune.js
```

`tools/solve-drop.js` 里的 `FIELD_HOURS` 就是节奏表，
改一个数字，它会重新解出整套掉率并写回数据文件 —— **不用手算**。

## 11. 存档结构

存储在浏览器 `localStorage`，键名 `fishplayer.save.v1`（另有 `...v1.bak` 备份）。

```
{
  v, coin, playTime, field, unlocked{},
  book: { fishId: { n, maxKg, colors{key:count}, first } },
  baits{}, baitSel, rods[], rodSel, lines[], lineSel, decors[],
  stats: { casts, catches, escapes, snaps, idleCatches, maxKg, maxKgFish, totalValue },
  settings: { sound, volume, ambient, idle },
  lastSeen, createdAt
}
```

支持版本迁移（缺失字段自动补默认值）、损坏时自动回退备份、一键导出到剪贴板。

## 12. 后续路线

### 上微信小程序
- 代码本身零依赖原生 JS，主要工作：`localStorage` → `wx.setStorageSync`、
  `Web Audio` → `wx.createInnerAudioContext`、Canvas API 对齐、接入广告/分享能力。

- 用 Tauri 或 Electron 打包同一份代码。
